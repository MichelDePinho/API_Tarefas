# Gerenciador de Tarefas

Aplicação web para gerenciamento de tarefas com backend em API REST e frontend web.
Permite cadastro e login de usuários, além de criar, listar, editar e excluir tarefas.

## Funcionalidades

- Cadastro de usuários
- Login
- Criação de tarefas
- Listagem de tarefas
- Edição de tarefas
- Exclusão de tarefas

## Tecnologias Utilizadas

Backend:
- Node.js
- Express
- JWT
- bcrypt
- dotenv

Frontend:
- HTML
- CSS
- JavaScript

## Estrutura do Projeto

API_TAREFAS  
FRONT_END_TAREFAS  

## Como Executar o Projeto

Backend:

1. Acesse a pasta API_TAREFAS
2. Execute npm install
3. Configure o arquivo .env
4. Execute npm start

A API será iniciada em http://localhost:3000

Frontend:

1. Acesse a pasta FRONT_END_TAREFAS
2. Abra o arquivo index.html no navegador

## Objetivo do Projeto

Projeto desenvolvido para praticar conceitos de API REST, autenticação de usuários e operações CRUD.
